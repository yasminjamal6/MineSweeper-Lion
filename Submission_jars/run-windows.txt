# MineSweeper-Lion (Windows)

## Download
Download and extract the project from:
https://drive.google.com/file/d/1t4S6BI7-M7AtyZHTD5AjbYc6uefRfiYI/view?usp=sharing

## Folder Structure
After extraction, the directory must look like this:

Submission_jars/
├── MineSweeper-Lion.jar
├── lib_win/
│   └── JavaFX libraries (win)
└── data/
    └── Questions.csv

Do not change the folder structure.

## Run Instructions
1. Open PowerShell.
2. Navigate to the Submission_jars folder:

   cd Submission_jars

3. Run the game:

   java --module-path .\lib_win --add-modules javafx.controls,javafx.fxml,javafx.media -jar MineSweeper-Lion.jar

## Requirements
- Windows
- Java 17 or higher
